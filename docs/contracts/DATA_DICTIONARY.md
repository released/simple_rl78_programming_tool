# Data Dictionary Index

The normative shared models are intentionally distributed by authority:

| Model | Normative location |
| --- | --- |
| PLP report/response/payload/event | `docs/protocol/PPS.md` |
| OIP/UPI header, manifest, descriptor, signature | `docs/offline/OIS.md` |
| SDK handles, operation, callbacks and errors | `docs/sdk/PSDK.md` |
| Firmware service/driver/HAL interfaces | `docs/firmware/FSDS.md` |
| GUI project/image/job/history/production models | `docs/gui/GSDS.md` |
| Shared primitive/error/capability/log/config/job contract | `docs/contracts/CONTRACTS.md` |
| Bridge application update profile and fixed image geometry | `docs/contracts/CONTRACTS.md` §4.3 |

This index drives current and future machine-readable schema generation. Any
field added to a generated schema must first be allocated in its normative
document.
