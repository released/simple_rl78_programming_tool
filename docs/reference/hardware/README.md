# Hardware Reference Extracts

This directory contains the board schematics and page extracts used during
M032 EVB, Nu-Link2-Me and RL78 programming-interface review. The images are
inspection aids; the corresponding official PDF remains authoritative.

- `NuMaker-M032SE_V1.3_Schematic.pdf` and
  `numaker-m032se-schematic-page2.png`: NuMaker-M032SE board reference.
- `nulink2me-schematic-4x.png`: enlarged Nu-Link2-Me schematic inspection aid.
- `renesas-recommended-circuits.pdf` and `renesas-circuit-page-*.png`: RL78
  programming-circuit reference and selected inspection pages.
