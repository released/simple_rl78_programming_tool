# ADR-0010: NuMaker-M032SE PB.3 Is Not Connected

- Status: Accepted / HIL pending
- Date: 2026-07-13
- Supersedes: the PB.3 target-VDD sense/range-gate portions of ADR-0004 and
  the M032-sense-retained statement in ADR-0009

## Context

ADR-0004 assigned PB.3/ADC0_CH3 to a divided target-VDD measurement and made
the 2.4-5.5 V result a programming-entry interlock. ADR-0009 later disabled the
equivalent function on Nu-Link2-Me while retaining it on M032. The approved
product direction is now consistent across both bridge boards: target-VDD
sensing is not wired and is not a programming prerequisite.

This change does not make an arbitrary target voltage electrically safe.
TOOL0 and RESET must still use interfaces referenced to the actual RL78 target
VDD, and the operator must measure the target supply externally before wiring.

## Decision

- PB.3/D1 is NC in the active NuMaker-M032SE RL78 programmer profile. Firmware
  does not select ADC0_CH3, enable or power the ADC, perform conversions, or
  require a voltage result.
- The M032 board adapter explicitly disables the target-VDD-sense capability
  and provides no fake voltage reading. Online and reset-triggered offline jobs
  therefore use the same mode-entry path without a VDD read/range gate.
- PA.4/D9 remains an optional external load-switch-enable output. It starts
  Low and remains physically unconnected in the current wiring profile; it is
  not a target-VDD source.
- PA.3 TOOL0, PA.5 RESET, PA.2 reserve, PB.14 LED, Protocol B timing and target
  profile checks are unchanged.
- The reusable board-I/O abstraction retains an optional sense capability for
  future board profiles. Neither current M032 nor Nu-Link2-Me enables it.

## Consequences

M032 no longer rejects an absent, undervoltage or overvoltage target before
Protocol B mode entry. An absent/nonresponsive target is handled by the bounded
handshake and safe pin release; voltage correctness is an external wiring/HIL
responsibility. A 5 V target must never be connected directly to the M032
3.3 V push-pull TOOL0 output.

## Evidence

- `firmware/board/m032_board_profile.[ch]`
- `firmware/board/m032_numaker_m032se_board.c`
- `firmware/board/m032_board_io.[ch]`
- Native PB.3-NC, disabled-sense and optional-capability tests.
- Required HIL: externally measure target VDD, verify PB.3 remains unused and
  capture TOOL0/RESET behavior for online and reset-triggered offline flows.
