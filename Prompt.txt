You are a senior embedded software architect.

Please design a complete software architecture and project specification for a professional RL78/G15 Programmer Tool.

==============================
Project Goal
==============================

Develop a complete RL78/G15 programmer.

The programmer consists of:

1.
Windows MFC GUI

2.
Nuvoton M032SE3AE EVB Firmware

The GUI communicates with M032 through USB HID.

M032 communicates with RL78/G15 through RL78 Protocol B UART.

This programmer must support BOTH

- Online Programming
- Offline Programming

This is NOT a bootloader.

Programming uses RL78 factory serial programming mode.

No modification is required for RL78 firmware.

RL78 firmware is still developed using Renesas CS+.

CS+ generates

*.mot

The GUI loads MOT files.

Architecture Requirements
==============================

The architecture shall follow

SOLID

Layered Architecture

Dependency Injection

Hardware Abstraction Layer

Platform Independent Design

No module shall directly access
another module's private implementation.

All communication shall be
interface-based.

Future devices must be added
without modifying existing GUI code.

Future communication methods

USB HID

CDC

UART

Ethernet

BLE

shall be replaceable by
changing only the Communication Layer.

The Programming Engine
must remain completely independent
from the Communication Layer.

==============================
Project Philosophy
==============================

This project is NOT an RL78/G15 programmer.

It is a reusable Programmer Platform.

RL78/G15 is only the first supported device.

Every architecture decision shall maximize
future reusability.

No design shall be tightly coupled
to RL78/G15.

The Programming Engine shall be reusable.

The GUI shall be reusable.

The Firmware shall be reusable.

Only Device Drivers shall be device dependent.
